# Accessibility taxonomy

The operational catalogue has72 criteria,52 syntactic/14 semantic/6 layout, derived from the frozen AccessGuru source with its MIT attribution. `catalog.json` preserves canonical definitions/disagreements; `curation.json` records operational admission. Catalogue size is not detector coverage.

Axe, syntax validation and observed DOM/layout evidence supply deterministic measures. Thirteen contextual textual paths use Decisions; image alternatives require verified frozen raster evidence and an explicit vision judge. Unsupported audiovisual/task evidence remains unassessed. A snapshot does not establish remote task success.

New GUI campaigns freeze Decisions as the contextual judge and Luna light separately as the image-alternative judge. The image role is independent of the repair pool and capture reviewer. Earlier implicit Decisions and explicit Luna high manifests retain their original selection, transport and cache identities.

`inventory.py` records document-bound opportunities. `assessment.py` binds blinded questions to audit/HTML hashes, model and rubric. Exact local-evidence cache reuse also retains source judgment receipts; changed context requires a fresh judgment. This is measurement idempotency, separate from harness experience learning.

Report original and each actual proposal with S/M/L failure counts, coverage, abstentions and introduced/eliminated opportunities. J+U+N/A=O. Removed content is not corrected accessibility. Missing evidence is not zero. Revisions preserve prior results and charges.

Runtime versions are declared in the producing modules and frozen receipts. Bounded controls/repeatability tests verify implementation; expert agreement and population accuracy require separate validation. The read-only `/taxonomy` catalogue makes no model calls.
